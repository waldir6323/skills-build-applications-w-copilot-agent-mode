# OctoFit Tracker Frontend

Este directorio contendrá la interfaz de la aplicación para clientes y profesores del gimnasio.

Características iniciales:
- Registro y login de usuarios
- Perfil de estudiante y perfil de profesor
- Catálogo de productos del gimnasio
- Control de clientes y membresías

Puedes iniciar la aplicación con un proyecto React o Next.js aquí.
